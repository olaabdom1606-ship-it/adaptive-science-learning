# مسار — Adaptive Science Learning

نموذج أولي لمنصة عربية لتطبيق **استراتيجية التعلم التكيفي الرقمي** في العلوم لدى طلاب الصف الأول الثانوي.

## موضوع الدراسة
**فاعلية استراتيجية التعلم التكيفي الرقمي في تنمية المفاهيم العلمية والتفكير التكنولوجي لدى طلاب الصف الأول الثانوي**

## الموجود في النسخة الأولى
- واجهة عربية RTL ومتجاوبة.
- اختبار تشخيصي تجريبي.
- محرك تكيف Rule-based بثلاثة مسارات: دعم، قياسي، متقدم.
- تحديد المفاهيم التي تحتاج تعزيزًا.
- رحلة تعلم شخصية.
- نموذج أولي للوحة المعلم وتحليلات التعلم.
- حفظ المسار في المتصفح.

> أسئلة الاختبار وأرقام لوحة المعلم بيانات تجريبية للبرمجة فقط، وليست أدوات البحث المحكّمة أو نتائج الدراسة.

## التشغيل
افتح `index.html` في المتصفح. لا تحتاج النسخة الحالية إلى خادم أو تثبيت حزم.

## المرحلة التالية
إضافة حسابات الطلاب، قاعدة بيانات، المحتوى العلمي النهائي، أدوات القياس المحكّمة، التقويم التكويني المستمر، وسجل قرارات محرك التكيف.
