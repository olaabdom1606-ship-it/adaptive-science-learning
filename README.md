# مسار — النسخة النهائية للمنصة

منصة موحدة للوحدة الثانية «الغلاف الجوي» في العلوم المتكاملة للصف الأول الثانوي 2026/2027.

## تشمل
- جلسة طالب وكود/اسم بحثي.
- تشخيص قبلي وبناء مسار علاجي/قياسي/إثرائي.
- أربعة دروس بشرح عربي ورسومات تعليمية عربية أصلية.
- تحقق تكويني ومعالجة تكيفية.
- أربع مهام للتفكير التكنولوجي.
- حفظ تقدم الطالب في المتصفح.
- تقويم ختامي وتقرير تعلم.
- لوحة معلم وسجل قرارات التكيف وRubric مقترح.

## قبل التطبيق الميداني
يجب مراجعة المحتوى علميًا وتربويًا وتحكيم أدوات القياس النهائية والتحقق من صدقها وثباتها. البيانات المحلية في هذه النسخة ليست قاعدة بيانات مركزية ولا نتائج بحثية.
