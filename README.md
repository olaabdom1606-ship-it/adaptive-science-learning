# مسار — منصة الغلاف الجوي
منصة ويب عربية تجريبية للتعلم التكيفي في الوحدة الثانية من العلوم المتكاملة للصف الأول الثانوي 2026/2027.

تشمل: تشخيص قبلي، ثلاثة مسارات تكيفية، الدروس 2-1 إلى 2-4، تحققات إتقان، مهام تفكير تكنولوجي، ولوحة تقدم.

مهم: بنود القياس الحالية تشغيلية لاختبار المنصة، وليست أدوات الدراسة النهائية قبل التحكيم والصدق والثبات.
